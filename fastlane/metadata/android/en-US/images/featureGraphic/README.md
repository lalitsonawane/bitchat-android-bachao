# Feature graphic (placeholder)

Place a single Play Store feature graphic in this directory:

- **Filename:** `featureGraphic.png` (recommended)
- **Size:** **1024 × 500** px
- **Format:** PNG (24-bit) or JPEG
- **Content:** Brand + short product promise; avoid dense UI chrome or tiny text

This file is required for Play Store listing completeness. Remove this README before automated metadata upload if your tool rejects non-image files.
