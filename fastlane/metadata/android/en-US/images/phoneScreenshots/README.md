# Phone screenshots (placeholder)

Add 2–8 PNG or JPEG screenshots here for Play Store / Fastlane upload.

## Requirements

- Show the real app UI (chat, mesh peers, geohash, permissions/privacy screens are good candidates)
- Typical phone size: **16:9 or taller**, at least **320 px** on the short side; **1080 × 1920** (or similar) is a safe target
- No misleading device frames required; avoid adding extra promotional badges on the image
- Do not include real personal data from testers

## Suggested filenames

```
01-mesh-chat.png
02-peer-list.png
03-geohash-channels.png
04-permissions-privacy.png
```

Fastlane expects image files directly in this directory (not nested). Remove this README before automated metadata upload if your Fastlane setup rejects non-image files, or exclude it in the supply configuration.
